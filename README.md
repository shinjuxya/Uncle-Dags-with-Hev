🎨 About the Project

Catching Dags with Hev is an independently developed student game project inspired by Filipino creativity, storytelling, and arcade games.

This project was made with lots of ideas, effort, and creativity, with the goal of making something fun, memorable, and worth coming back to. 🇵🇭

💻 Game Information

* 🖥️ Platform: Windows Desktop
* ⚙️ Runtime: Electron
* 💡 Built With: HTML, CSS, and JavaScript
* 💾 Save System: Local device storage
